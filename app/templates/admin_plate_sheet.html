How to review a story
  1. Paint every missing page. One image call each; stopping and starting again picks up where it left off.
  2. Open a tile and approve the best candidate. A plate is never overwritten — a new try waits beside it.
  3. Fix one thing by typing what should change ("warmer light", "the path on the right"), then paint again.
  4. Turn the start gate on once every page is approved; that set becomes the template new books are drawn on.
