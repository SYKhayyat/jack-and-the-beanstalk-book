# Comparison: ten real people, ten AI personas

*Skeleton. Nothing below is filled in yet. The shape, the questions and the
scoring are written now so both response sets can be read against the same
ruler when they exist.*

## What is being compared

Two sets of ten responses to the same book, gathered for two different reasons:

| | Real ten | AI ten |
| --- | --- | --- |
| Who | Ten adults recruited through CloudResearch Connect, none of whom built the app | Ten AI personas, each run against the same book, locally, on the developer's own key |
| What they see | The whole 20-page PDF, made from a photo they uploaded | The same book, described in the same words |
| What they are asked | [engage-survey.md](engage-survey.md) — eight questions | The same eight questions, asked of each persona |
| What the set is for | The evidence: what a real person says about the book | The rehearsal: a way to ask ten more "readings" without paying for another crowd study |
| Cost | ~$10 of Connect fees (or $0 with the first-study waiver) plus ~$1.20 of picture calls | The developer's own API spend, at cost |

The honest framing for the class: **the real ten are the finding. The AI ten
are a method test.** A persona is a model of a reader, not a reader. What the
comparison is allowed to claim is where the two agreed, where the AI set was
blind, and where the AI set saw something the humans did not — because that last
column is the only reason to run the AI set at all.

## How the comparison is scored

Both sets answer the same eight questions. Three of them are closed, so they can
be counted; the rest are read and quoted.

| Question | Real ten | AI ten |
| --- | --- | --- |
| Q1 — looks like them | count of Yes / Roughly / No / Cannot tell | the same, per persona |
| Q2 — story rings true | count of Yes / Mostly / No / Did not read | the same |
| Q3 — looks professional | count of Yes / Almost / No / Not sure | the same |
| Q4 — one thing to change | the ten quotes, verbatim | the ten quotes, verbatim |
| Q5 — anything wrong at close range | count of Yes / No | the same |
| Q6 — where, and what | the ten quotes, verbatim | the same |
| Q7 — would you show it | count of Yes / Sorry / No | the same |
| Q8 — anything else | the quotes | the quotes |

Rule for reading the counts: **a count is only evidence when the denominators
are the same.** If three of the AI personas answered Q5 "No" because their
prompt never told them to look closely, that is a method failure and it is
written down as one, not averaged away.
